# Demo A 视觉与语音推理（ONNX 全栈）
#
# ⚠️ 本文件**不含 torch / torchvision / ultralytics**，与旧版不同。
#
# 原因（本项目实测结论，勿轻易改回）：
#   本机阿里云镜像带宽约 343 KB/s，torch 2.7.0+cu128 + torchvision 约 2.7 GB
#   → 约 137 分钟。而 Demo A 的三个模型都不需要 torch：
#     YOLO11n-> onnxruntime-gpu（官方 onnx 权重，仅 10.42 MiB）
#     InsightFace   -> onnxruntime-gpu
#     faster-whisper -> CTranslate2（自带 CUDA）
#   合计约 500 MB。已实测本机 CUDAExecutionProvider 可用（device=GPU）。
#
# 安装请用一键脚本（它包含三个必须遵守的顺序约束）：
#     python scripts/setup_demo_a_vision.py
# 直接 pip install 本文件会踩以下坑：
#   1) insightface 无条件依赖 CPU 版 onnxruntime，会覆盖 GPU 版；
#   2) faster-whisper 同样会拉 CPU 版 onnxruntime 再覆盖一次；
#   3) 本机沙箱守卫会拦截 uninstall / --force-reinstall，**无法靠重装修复**。
# 因此 insightface 与 faster-whisper 一律用 --no-deps 装，
# 且 onnxruntime-gpu 必须最后安装。

# GPU 推理运行时（必须最后装）
#
# 版本结论（实测修正，最终锁定 1.26.0）：
#   本机**没有 CUDA Toolkit**（只有驱动），但
#   D:\ComfyUI 的 torch 2.7.0+cu128 自带完整 CUDA 12.8 运行时
#   （cublasLt64_12 / cudart64_12 / cudnn64_9 等），
#   onnxruntime-gpu 1.26.0 + 复用那套 DLL → **CUDA provider 真实生效**
#   （实测 providers = ['CUDAExecutionProvider','CPUExecutionProvider']，
#     is_fallback=False，YOLO11n 推理 20.6 ms）。
#   只读复用（os.add_dll_directory + ort.preload_dlls），不复制不修改 ComfyUI。
#
#   ⚠️ 过程中两次判断错误，都已修正，勿再走回头路：
#   (1) 曾只查官方文档的 CUDA 版本表就锁定 1.26.0，未验证 Python 版本约束；
#       实际上 **cp313 轮子只有 1.20.0/1.20.2 有**（1.21~1.26 列表上
#       只显示 cp310/311/312），曾据此误判 1.26.0"装不了"而改锁 1.20.2 ——
#       **实测 1.26.0 能装上且 CUDA 正常**，说明轮子列表也不完全可信，
#       终究要以「装上去 + 真实会话验证」为准。
#   (2) 曾用 1.30（CUDA 13 构建），报缺 cublasLt64_13.dll 后**静默降级 CPU**。
#       判定必须用 Session.get_providers()，**不能信 get_available_providers()** ——
#       后者在降级时依然列出 CUDAExecutionProvider。
