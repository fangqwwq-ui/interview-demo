技术验证版 · 简历作品集

多模态 AIGC 工具链 · 面试 Demo 集

把简历里写到的多项 AIGC / 多模态能力，用可运行、可复现的代码复现为四个演示模块，并统一到带「指标口径页」的门户里。每个性能数字都能指出定义、公式、数据集与计算脚本——实测达不到简历值的，按实测报，不凑数。

你能在这里看到什么

这是一份可验证的技术作品，不是概念 PPT。四个模块分别复现了「安防智能体」「文案去 AI 味」「漫剧自动生产」「指标口径门户」四类能力；点开仓库里的演示录屏，能直接看到它们跑起来的样子。

四个演示模块

DEMO A · 多模态安防

视觉检测 → 语音提问 → 智能应答 → 工单落库

四层串联的智能安防 Agent：看懂画面里的目标，听懂自然语言提问，从知识库检索答案，并把事件写成工单。

DEMO B · 文案人类化

原文 / 开源内核改写 / 自研改写 三路对照

把"AI 味"很重的文案改得自然通顺，并支持原文、开源方案、自研规则三路并排对比，质检可量化。

DEMO C · 漫剧流水线

剧本 → 出图 → 配音 → 合成，可断点续跑

一条命令把剧本变成短视频；中断后重跑会跳过已完成步骤，不重复烧钱出图，只重做失败步。

DEMO D · 统一门户 + 口径页

统一入口 + 每个数字都可溯源

把所有模块聚到一个门户里，并公开每个性能指标的"定义 / 公式 / 数据集 / 脚本 / 实测值"，接受追问。

整体架构

图片 / 语音 / 文案 / 剧本 → Demo A 安防 Demo B 文案 Demo C 漫剧 → Demo D 门户(8200)

各模块通过统一底座与 HTTP 服务解耦，可独立演示，也可串成一条端到端链路。

口径与归属（如实说明）

本仓库是「独立复现版」，不声称等于简历中的生产事实。
· humanize-chinese 为第三方开源（MIT），仅作检测/改写内核调用，非自研。
· aigc-comic 为既有自研项目，本 Demo 仅做 HTTP 接入与复现；其「状态机 + 断点续跑」是既有能力，不声称自研。
· 未接生产 LLM 的环节（Demo B 自研改写臂、Demo C LLM 审核通道）如实标注为 n/a，不粉饰。
· 完整边界与来源声明见仓库 README 与门户「来源声明页」。
