# Demo A 视觉与语音推理（ONNX 全栈）
#
# ⚠️ 本文件**不含 torch / torchvision / ultralytics**，与旧版不同。
#
# 原因（本项目实测结论，勿轻易改回）：
#   本机阿里云镜像带宽约 343 KB/s，torch 2.7.0+cu128 + torchvision 约 2.7 GB
#   → 约 137 分钟。而 Demo A 的三个模型都不需要 torch：
#     YOLO11n-> onnxruntime-gpu（官方 onnx 权重，仅 10.42 MiB）
#     InsightFace   -> onnxruntime-gpu
#     faster-whisper -> CTranslate2（自带 CUDA）
#   合计约 500 MB。已实测本机 CUDAExecutionProvider 可用（device=GPU）。
#
# 安装请用一键脚本（它包含三个必须遵守的顺序约束）：
#     python scripts/setup_demo_a_vision.py
# 直接 pip install 本文件会踩以下坑：
#   1) insightface 无条件依赖 CPU 版 onnxruntime，会覆盖 GPU 版；
#   2) faster-whisper 同样会拉 CPU 版 onnxruntime 再覆盖一次；
#   3) 本机沙箱守卫会拦截 uninstall / --force-reinstall，**无法靠重装修复**。
# 因此 insightface 与 faster-whisper 一律用 --no-deps 装，
# 且 onnxruntime-gpu 必须最后安装。

# GPU 推理运行时（必须最后装）
#
# ⚠️ 版本经「查轮子 + 查文档」双重确认，不可随意改：
#
#   1) Python 版本约束（更硬）：本项目 venv 是 **Python 3.13**，
#      而 onnxruntime-gpu 的 **cp313 轮子只存在于 1.20.0 / 1.20.2**；
#      1.21~1.26 只有 cp310/311/312（无 cp313），1.27+ 才有 cp313。
#
#   2) CUDA 主版本绑定：onnxruntime >= 1.27 是 **CUDA 13** 构建
#      （要 cublasLt64_13.dll），<= 1.26 是 **CUDA 12.8**（要 _12）。
#      本机只装了 NVIDIA 驱动、没有 CUDA Toolkit，但
#      D:\ComfyUI 的 torch 2.7.0+cu128 自带完整 CUDA 12.8 运行时，
#      所以必须用 CUDA 12 构建，**只读复用**那套DLL，无需几 GB 的 Toolkit。
#
#   两条约束相交（cp313 ∩ CUDA12）→ **唯一可用版本是 1.20.2**。
#   （初版误写 1.26.0，装的时候才报错「无 cp313 轮子」—— 版本假设必须先查轮子。）
#
#   3) ORT 在 CUDA 缺依赖时**不抛异常，只静默降级 CPU**，
#      而 get_available_providers() 依然列出 CUDAExecutionProvider。
#      只看那份清单会误判成「GPU 可用」，必须用 Session.get_providers() 判定。
onnxruntime-gpu==1.20.2
